# Arkade SDK Demos

This repo is an effort to create self-contained demos for the [Arkade TypeScript SDK](https://github.com/arkade-os/ts-sdk), on both production (mainnet) and testing (mutinynet) networks, allowing us to:

1. Track breaking changes as the SDK is updated
2. Identify missing or poorly-supported features
3. Test code examples used on the [Arkade docs](https://docs.arkadeos.com)
